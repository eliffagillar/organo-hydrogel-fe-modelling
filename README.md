# Organo-Hydrogel Finite Element Modelling

This repository contains Python and Abaqus scripts developed as part of an MSc research project investigating the mechanical response of heterogeneous soft materials using particle-matrix finite element models inspired by organo-hydrogel systems.

## Computational workflow

The repository includes scripts used for:

- two-dimensional particle-matrix model generation;
- particle-number and modelling-assumption development studies;
- particle-to-matrix stiffness-ratio analysis;
- stochastic microstructure analysis;
- exploratory gravity-plus-compression modelling; and
- preliminary three-dimensional model development.

## Particle-number development

Particle-number development was investigated using both plane-stress (CPS) and plane-strain hybrid (CPEH) formulations.

Three particle-number cases were generated by changing the target particle density, corresponding approximately to 10, 108 and 1089 particles. The remaining modelling procedure was kept consistent within each formulation.

The representative scripts are:

- `particle_number_CPS.py`
- `particle_number_CPEH.py`

## Stiffness-ratio analysis

Four particle-to-matrix stiffness ratios were investigated: R = 1, 2, 5 and 10.

The same model-generation and loading procedure was used for all four cases, with the stiffness ratio and corresponding job/output names changed between runs.

## Stochastic analysis

Eight stochastic realisations were generated using seeds 42, 101, 202, 303, 404, 505, 606 and 707.

The same modelling procedure was used for each realisation, with the random seed and corresponding model/job names changed between runs.

## Gravity model

An exploratory gravity-plus-compression model was developed during the project. These simulations were used to investigate the effect of gravitational pre-deformation and were not included in the main quantitative stiffness-ratio comparison.

## Preliminary 3D model

A preliminary three-dimensional model was developed as an extension of the two-dimensional framework. It contains spherical inclusions within a three-dimensional matrix and was treated as a feasibility/model-development study rather than part of the main quantitative 2D analysis.
