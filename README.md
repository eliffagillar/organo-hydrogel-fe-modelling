# Organo-Hydrogel Finite Element Modelling

This repository contains Python and Abaqus scripts developed as part of an MSc research project investigating the mechanical response of heterogeneous soft materials using particle–matrix finite element models inspired by organo-hydrogel systems.

The computational workflow includes:

- automated generation of two-dimensional particle–matrix microstructures;
- construction of finite element models in Abaqus;
- particle-to-matrix stiffness-ratio analyses;
- generation of stochastic microstructural realisations;
- post-processing of Abaqus output databases; and
- preliminary three-dimensional model development.

The main quantitative analyses were performed using two-dimensional models. The three-dimensional model was developed as a preliminary extension of the computational framework.

## Software

- Abaqus/Standard
- Python
- NumPy
- Fiji/ImageJ was used separately for preliminary microscopy image analysis.
